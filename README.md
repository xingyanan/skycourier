# 天空快递

单手物理投递小游戏的浏览器原型。狐狸快递员站在浮岛上，把包裹投进蓝色邮箱。核心循环和关卡数据都不碰页面结构，方便以后迁到微信小游戏。

现在能玩十二关，从晴空投递、侧风、游动邮箱，到双弹板、窄口、逆风、邮票、错层、钟摆、顺风窄口、双岛错拍和灯塔夜航。每关只多一个要学的东西，写在 `DESIGN.md`。

画面用 `public/assets` 里的插画。某张图没载入时，那一块仍用原来的程序绘制，游戏不会空屏。没有登录、广告、内购，也不使用微信的标志。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

终端会打印本地地址，默认是 [http://127.0.0.1:4317](http://127.0.0.1:4317)。用手机竖屏，或把浏览器窗口拉成竖条，最接近小游戏的手感。

```bash
npm test        # 检查三关都有能投进的力度窗口，并回放一遍
npm run typecheck
npm run build   # 输出到 dist/
npm run preview
```

地址后面加上 `?debug=1` 会画出碰撞盒、云海死亡线，以及轨迹被藏起来的后半段，方便改关卡。

## 怎么玩

- 按住包裹向后拖。拖动方向的反方向是出手方向，拖得越远力度越大。
- 松手投出。拖得很短再松开会取消，不计入次数。
- 白点只画出预测轨迹的前半段。后半段、弹板之后会去哪，要自己判断。
- 紫色弹板在一次投递里只会把包裹向上弹起一次。
- 包裹进了邮箱投递口就过关。
- 掉进底部云海、飞出画面，或停在岛上却没进邮箱：这次失败，包裹回到狐狸手里，次数保留。
- 右下角圆箭头：整关重来，次数清零。胜利后也可以点「再来一次」。
- 左上角关卡数字：在已做好的关卡之间切换。
- 电脑上鼠标等同于手指。`R` 重开，`1` `2` `3` 直接选关。

星级按这一关的投递次数算：1 次三星，2 次二星，更多是一星。次数在松手时加一。邮票加星的规则已经写进结算，前三关先不放邮票，避免一关教两件事。

## 目录

```text
public/assets  狐狸、包裹、邮箱、弹板、浮岛、云、风向旗和晴空背景
src/game        物理、关卡、操作、绘制。不要在这里写 document 或 wx
src/game/levels.ts
                关卡配置。加第 4 关只改这里
src/platform/browser
                浏览器画布、指针和音效
src/platform/wechat/wechatHost.ts
                微信小游戏移植缝，尚未在微信开发者工具里运行
DESIGN.md       操作、胜负、星级，以及计划中的 12 关
```

## 迁到微信小游戏

游戏通过 `GameHost` 拿画布、每帧时间和已经换成逻辑坐标的触摸。浏览器实现在 `src/platform/browser/browserHost.ts`。`createWechatHost` 用 `wx.createCanvas` 和触摸事件填同一个接口，再把 `start` 逻辑从 `src/main.ts` 换过去即可。

物理用固定的 1/120 秒步进，坐标是 390×780，y 向下。关卡里的重力、风、岛、弹板、邮箱和移动都是数据。

这个文件里的微信适配还没在真机或开发者工具里验证过。
